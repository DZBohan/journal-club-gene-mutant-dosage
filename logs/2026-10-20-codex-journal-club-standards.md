# Reusable journal club standards

User requested a reusable workflow covering article interpretation and PPT creation, and explicitly authorized pushing it to this repository.

Added standards for evidence tracing, HTML interpretation, PPT layout and notes, source-panel attribution, teaching arithmetic, validation and delivery. Added task, evidence, panel, storyboard and review templates plus a repository AGENTS entry point. Existing paper materials remain unchanged.

Motivation: recent discussions exposed the need to distinguish samples from simulations, reference knowledge bases from patient cohorts, core algorithms from downstream models, and signed effects from relationship strength. Teaching examples must satisfy marginal-count constraints; randomization diagrams must preserve the constraints they claim. Original figure legends, including nested boxes and changing color semantics, must be read rather than inferred.

Known legacy issues are not fixed by this documentation change: the initial SelectSim slide 3 teaching example used an impossible overlap; slide 6's schematic did not preserve the sample-burden heterogeneity described in its caption. Chat explanations clarified these issues, but the earlier delivered deck must not be represented as corrected by this standards commit. A future deck revision should also recheck all legends against the source paper.

Scope: documentation and reusable templates only. No new paper PDFs, private discussion transcripts or generated slide binaries added. Existing repository name and approved files preserved.
