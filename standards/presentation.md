# 英文 Journal club PPT 标准

## 叙事与时间

默认英文、16:9、约 20 分钟。建议时间分配：文章和背景 3 分钟；目标与方法 5 分钟；具体结果 8 分钟；局限、组内价值和总结 4 分钟。按文章调整，不以凑齐页数为目标。

主线：研究背景 → 未解决问题 → 工具/实验目标 → 输入和方法 → 验证 → 具体结果 → 下游分析 → 局限与本组应用 → 总结。

每页只承担一个主要问题。标题应准确表达本页问题或发现，避免“所有单突变都不够”等过强概括。第一处定义符号和缩写；模型边界、观察值与参数、核心工具与下游模型必须明确。

## 视觉硬标准

- 白底。标题 Arial 32 pt；所有新增正文、公式、坐标标签、表格、图例、引用和页码 Arial 18 pt，仅两档。
- 标题尽量一行。空间不足时改写、拆页、裁切放大，不缩小字体来塞内容。
- 文字保持 PPT 原生可编辑；自绘图形在外部生成后单独插入，保留 SVG 或生成脚本。不得把整页截图冒充可编辑 PPT。
- 原文 figure panels 保留其原始字体与配色，不为满足新增文字字号而篡改图中数据。通过裁切、放大和分拆保障可读；必要时添加独立可编辑的解释标签。
- 使用 [palette.json](../figures/palette.json) 的八色配色。正文可用黑色；浅色柱数字用黑色。相同语义跨页同色，不同语义不得无说明地共用颜色。
- 每篇建立自己的 semantic color map。INCOMMON 的 M/W 和 A/B/C 是该文映射，不是所有论文都必须沿用的分类含义。
- 原图颜色例外要明确标注：例如原图某页绿色表示 CO，下一页绿色表示 M-enriched，应重新解释，不能沿用上一图的图例。
- 不使用中文破折号或英文 em/en dash 作为句子标点；使用句号、冒号、括号。数学减号使用真正的减号；基因对、复合词连字符保留其语义。
- 分区对齐；图例明确成行成列；标题与内容、图与图例之间留出空间。检查上方拥挤、下方空白、标签相撞和相邻 panel 残片。
- 保留已认可的有效结构、教学数字和完整图例。简洁不能删除关键步骤，也不能把已完成的 DNA 拷贝图降级成文字。

## 原文 panel 使用

每个主要结果必须有可追溯的证据图或表。优先原文 panel，而不是全部重画成概念图。

1. 阅读完整图注和对应 Methods，再选择 panel；不能根据颜色猜含义。
2. 登记 PDF 页、figure/panel ID、裁切范围、来源和用途。
3. 保留必要坐标、刻度、图例、样本数与 panel 标记。不得裁掉影响解释的部分或带入相邻图碎片。
4. 不拉伸比例，不重新着色原始数据，不手工修点。不使用生成式图像替代科学结果。
5. 若重新绘制数据，标为 Redrawn from，并记录数据来源和重建方式；不得将近似读图值标为精确值。
6. 每页注明 Fig. X / panel，完整引文和细节放备注。原图无法读清时拆页，不堆满一页。

自绘图负责补充方法、变量对应、连续教学例子和对照设计；原图负责提供论文证据。两者不能混称。

## 演讲备注

每页必须包含：

- 本页目的与一段可直接讲的英文说明。
- 图怎么读，符号第一次出现的定义，关键例子。
- 定量结果和来源，教学数字明确声明。
- 需要口头补充的假设、限制与不可推出的结论。
- 前后页过渡、建议讲述秒数、一个可能被问的问题及准确回答。

复杂细节放备注或 backup slides，但主幻灯片仍须自洽。不能用备注来掩盖正文错误。

## 版本和交付

单页修改也直接交付 PPTX，不要求用户另行索要转换。全套交付 PPTX＋PDF 预览，保留生成代码、素材登记表、逐页计划及检查记录。PDF 不是 PPTX 的替代物。

先渲染全部页面，检查联系表与每张细节页，再核对导出页数、备注、文本可编辑性、字号和边界。用户只提供手改截图时保留截图作为参照，不声称拥有其最终可编辑版本。
