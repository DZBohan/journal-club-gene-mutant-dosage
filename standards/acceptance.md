# 交付验收清单

每次复制 [review.md](../templates/journal-club/review.md) 并记录证据。检查结果为 PASS、FAIL、NOT CHECKED 或 N/A；N/A 必须说明理由。任何科学事实错误或影响读图的裁切、错标均阻断发布。已交付文件发现错误应标为待修订，不能因聊天中解释过就认为文件已修复。

## 科学与逻辑

- [ ] 题目、作者、年份、DOI、PDF 版本核对。
- [ ] 重要主张均对应 evidence.csv；正文、Methods、图注和相关补充材料交叉核查。
- [ ] 背景、目标、方法、具体结果、局限、本组价值齐全。
- [ ] 核心算法、队列应用、基准测试与下游模型边界清楚。
- [ ] 样本、患者、模拟、队列、基因对的单位无混用；分母和并集正确。
- [ ] 所有教学数字重新计算，包含边际约束、概率和、权重与跨页一致性。
- [ ] 随机图示与其声称保留的约束一致；假设值与真实结果区分。
- [ ] 每图轴、图例、颜色、嵌套框、空白、对数转换和差值含义逐一核对。
- [ ] FDR 不是单个发现为假的概率；效应量不是显著性；相关不是因果；阴性对照不等于绝对无功能。
- [ ] “验证”具体说明验证形式；临床预测不超出实际验证证据。
- [ ] 本组建议基于已知课题，不捏造数据、合作或实验完成情况。

## HTML

- [ ] UTF-8、单文件、离线可阅读，图片和公式完整。
- [ ] 目录、图注、缩写、面板解读、来源可用。
- [ ] 放大/关闭、键盘、折叠、窄屏、打印经实际测试或明确标为未测试。
- [ ] 中英文版本若同时存在，数字和结论一致。

## PPT

- [ ] 白底、16:9、新增文本 Arial 32/18 pt；原文 panels 的字体例外明确。
- [ ] 新增文字可编辑，图形单独插入，有源文件。
- [ ] 原文 panel 可读、引用完整、无裁切损害、无形变或残片。
- [ ] 无拥挤、遮挡、越界、低对比度、无意义大空白；图例与主体适当分离。
- [ ] 全部页渲染后逐页检查，而不只检查首页或联系表。
- [ ] 每页有英文演讲备注，建议用时合计符合报告目标。
- [ ] 无重复页、错误页码、未替换占位符、残留旧稿数字。
- [ ] 交付 PPTX 和 PDF，文件可打开，页数一致。

## 发布

- [ ] 保存证据表、素材表、生成源、审查记录和版本状态。
- [ ] 已知问题明确记录；未核实的关键结论不作为确定事实发布。
- [ ] 保留批准内容及用户修改，未误把旧草稿称为批准稿。
- [ ] 检查本次 diff、敏感信息、原文版权和误加入的大文件。
- [ ] 获得当次 push 授权后普通推送，验证远端提交；失败如实报告。
