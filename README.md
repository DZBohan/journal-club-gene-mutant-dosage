# Journal club: gene mutant dosage (INCOMMON)

Preparation for a journal club presentation on:

Calonaci N, Krasniqi E, Colic D, et al. **Gene mutant dosage is associated with prognosis and metastatic tropism in 60,000 clinical cancer samples.** *Nature Genetics* (2026). [doi:10.1038/s41588-026-02666-z](https://doi.org/10.1038/s41588-026-02666-z)

Working title: 从突变阳性到突变剂量：临床测序能多告诉我们什么？ (From mutation-positive to mutant dosage: what more can clinical sequencing tell us?)
